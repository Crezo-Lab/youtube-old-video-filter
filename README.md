# YouTube 古い動画フィルター (NY)
> **YouTube Old Video Filter (NY)** — Hide old videos, watched videos, Shorts, and blocked channels from YouTube feeds.

「ショーツを見ない古い人間なので」——YouTubeのホームや検索結果から、古い動画・Shorts・視聴済み動画・指定チャンネルを根こそぎ排除し、本当に見たい最新長尺動画だけを残すChrome拡張機能です。

---

## 🌟 主な機能 (Features)

1. **古い動画の非表示 (Old Video Filter)**
   - 「1年以上前」「半年以上前」「1か月以上前」など、指定した期間より古い動画を一覧から自動的に非表示（または薄く表示）。
2. **Shorts（ショート動画）の完全排除 (Hide Shorts)**
   - ホームの棚、検索結果、サイドバー、関連動画のShortsを完全ブロック。
3. **視聴済み動画の非表示 (Hide Watched Videos)**
   - 再生バーが一定割合（デフォルト80%）以上進んでいる動画を自動非表示。
4. **お気に入りチャンネルの例外設定（ホワイトリスト）**
   - 古くても見たいチャンネルは、ワンクリックまたは `@handle` で除外登録可能。
5. **指定チャンネルの完全ブロック（ブラックリスト）**
   - 目に入れたくないチャンネルをワンクリックで非表示。
6. **多言語対応 (Multilingual)**
   - 日本語、英語、繁体字中国語、簡体字中国語、韓国語、スペイン語に対応。

---

## 🚀 インストール方法 (Installation)

1. 右側の **[Releases](https://github.com/Crezo-Lab/youtube-old-video-filter/releases)** から最新の `youtube-old-video-filter.zip` をダウンロードして解凍します。
2. Google Chrome で `chrome://extensions/` を開きます。
3. 右上の **「デベロッパー モード」** をONにします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダを選択します。
5. ツールバーに **NY** アイコンが表示されたら完了です！
